# Quiet Index — Индекс тихого места

[![Build and deploy](https://github.com/yetit/quiet-index/actions/workflows/deploy.yml/badge.svg)](https://github.com/yetit/quiet-index/actions/workflows/deploy.yml) [![Smoke](https://github.com/yetit/quiet-index/actions/workflows/live.yml/badge.svg)](https://github.com/yetit/quiet-index/actions/workflows/live.yml)

**Демо: <https://yetit.github.io/quiet-index/>**

**Где тихо, темно и далеко от людей?** Карта, которая оценивает любую точку региона от 0 до 100 — для путешественников, кемпинга и тех, кто ищет, куда уехать поработать. Всё на открытых данных, расчёт в браузере: без сервера и ключей.

English: [README.md](README.md).

Пилотный регион — Черногория целиком, сетка ~250 м. Архитектура «любой регион»: bbox в `regions.config.mjs`, одна команда, результат в git.

## Что видно

- **Карта** окрашена индексом сразу при входе (предрассчитанная сетка — один файл ~1 МБ). Чипы переключают на отдельный слой: тишина, темнота, безлюдье, природа, связь.
- **Клик по точке** — оценка, пять оценок по слоям и измерения, из которых они сложились: расстояние до ближайшей дороги и её класс, до железной дороги, аэропорта, ближайшего здания и вышки, ночная радиометрия, плотность населения, доли леса / воды / открытых земель.
- **Веса** — ползунки. Индекс — взвешенное среднее пяти слоёв, ничего скрытого. «Связь» по умолчанию с весом 0 — поднимите, если нужен интернет.
- **Поиск места** (Photon), **RU / EN**, лист снизу на телефоне и всё состояние в ссылке (`?p=lat,lon&w=…&l=…&lang=…`).

## Как считается

Каждая клетка (~250 м, квадратная в Web Mercator) получает пять оценок 0–100. Пороги — эвристики, подобранные по пилотному региону, все в одном файле: [src/core/index.ts](src/core/index.ts).

| Слой | 100 — это | 0 — это | Формула |
|---|---|---|---|
| **Тишина** | ни дороги, ни улицы, ни ж/д, ни аэропорта в пределах слышимости | прямо на дороге | `min` по источникам от `расстояние / радиус`, линейно; радиусы: motorway 2,5 км, trunk 2 км, primary 1,2 км, secondary 700 м, tertiary 400 м, улица residential / unclassified 150 м, ж/д 1 км, аэропорт 4 км |
| **Темнота** | ночная радиометрия ≤ 0,25 нВт/(см²·ср) | ≥ 50 нВт/(см²·ср) | лог-шкала между порогами |
| **Безлюдье** | никого в 2×2 км и ни одного здания в радиусе 1 км | плотный город, дом прямо здесь | среднее лог-оценки плотности (0 при ≥ 5 000 чел/км²) и `расстояние до здания / 1 км` |
| **Природа** | 2×2 км леса и воды | пашня или застройка | лес % + вода % + ½ · открытые естественные земли % (кустарник, луга, скалы, снег, болота) |
| **Связь** | вышка из OSM в радиусе 1 км | ни одной в 8 км | линейно от 1 до 8 км; **данные неполные**, см. ограничения |

Индекс = Σ вес · оценка / Σ вес. Веса по умолчанию: тишина 35, темнота 25, безлюдье 20, природа 20, связь 0.

Тяжёлая часть — один раз при сборке данных (`npm run fetch -- montenegro`, около 5 с расчёта после загрузок): расстояния — точное евклидово преобразование расстояния на подсетке в 5 раз мельче (~50 м), население и покрытие — суммы по окну 2×2 км через интегральные таблицы. Браузер только распаковывает сетку, применяет формулы и рисует canvas в image-источник MapLibre. Сдвиг ползунка перекрашивает все 526 000 клеток за миллисекунды.

## Источники и лицензии

| Слой | Источник | Лицензия | Примечания |
|---|---|---|---|
| Дороги, ж/д, аэропорты, здания, вышки, граница | [OpenStreetMap](https://www.openstreetmap.org/copyright) через Overpass API | ODbL 1.0 | Дороги: `motorway … tertiary` с их `_link`, плюс `residential` и `unclassified` одним классом «улица». Аэропорты: аэродромы с кодом IATA и ВПП длиннее 1,5 км. Вышки: `tower:type=communication`, `communication:mobile_phone=yes`, `man_made=communications_tower`. |
| Ночной свет | NASA Black Marble **VNP46A2** (VIIRS DNB, gap-filled, с коррекцией BRDF и луны, суточный) через [NASA GIBS](https://www.earthdata.nasa.gov/engage/open-data-services-and-software/api/gibs-api) | данные NASA, без ограничений | GIBS отдаёт палитровые PNG; радиометрия восстановлена по опубликованной цветовой карте (бины 0,1 нВт, насыщение на 38,2). Годовое значение — медиана 24 ночей (1-е и 15-е число каждого месяца 2025), пиксель ~450 м на zoom 8. |
| Население | [WorldPop](https://www.worldpop.org/) 2020, 100 м, unconstrained, файл по стране | CC BY 4.0 | Сумма по файлу — 615 212 человек, сходится с переписью. |
| Покрытие земли | [ESA WorldCover](https://esa-worldcover.org/) 2021 v200, 10 м | CC BY 4.0 | Читается обзорный уровень 80 м из Cloud-Optimized GeoTIFF range-запросами, только окно региона. |
| Подложка | [OpenFreeMap](https://openfreemap.org), стиль Positron, © OpenMapTiles © OpenStreetMap | ODbL / BSD | Тайлы грузятся онлайн. |
| Поиск | [Photon](https://photon.komoot.io) от komoot | ODbL (данные OSM) | Запросы онлайн, без ключа. |

Производный растр в `public/data/<регион>/` смешивает эти источники; считайте его ODbL + CC BY 4.0 (указывайте участников OpenStreetMap, WorldPop, ESA WorldCover, NASA). Код — MIT.

### Что планировалось и чем заменено

- **Карты шума ЕС (END / EEA)** как эталон: Черногория не входит в отчётность по директиве о шуме — сверять не с чем. Не подключено.
- **VNP46A4 (годовой Black Marble)** требует токен Earthdata; **годовые композиты EOG** — регистрацию; **World Atlas** (Falchi 2016) — CC BY-NC и 684 МБ. → Суточный VNP46A2 через GIBS (без ключа), медиана 24 ночей.
- **GHS-POP** — архивы тайлов 10°×10° по сотни МБ; **WorldPop** даёт файл по стране в 10 МБ с той же по сути лицензией (CC BY 4.0). → WorldPop.
- **Copernicus Global Land Cover (CGLS-LC100)**: публичный S3-бакет в октябре 2026 отвечает 404. → ESA WorldCover 2021, тоже CC BY 4.0 и детальнее.
- **OpenCelliD** требует ключ; открытые данные **Ookla / nPerf** — CC BY-NC-SA. → Вышки из OSM, слой выключен по умолчанию и помечен как неполный.

## Ограничения — прочитайте, прежде чем верить числу

- **Эвристики, не акустика.** Класс дороги заменяет трафик; экранирование рельефом, ветер, ограничения скорости и время суток не учитываются. Tertiary в 400 м — «тихо»; автомагистраль в тоннеле считается как на поверхности.
- **Улицы слышны только в 150 м.** `residential` и `unclassified` — один класс с коротким радиусом; `service`, `track` и тропы — не источники вовсе. Оживлённая деревенская улица и тупиковый проезд выглядят одинаково.
- **Клетки 250 м.** Клик привязывается к центру клетки, расстояния могут отличаться до ~180 м. Хранятся с шагом 25–100 м.
- **Полнота OSM.** Здания в Черногории хорошо отмечены в городах и неровно в сёлах; вышки связи — лишь местами. «Связь» — подсказка, а не покрытие.
- **Ночной свет** — пиксели ~450 м; снег, пожары и огни судов его завышают; только 2025 год.
- **Население** — модель 2020 года (WorldPop), туристов и сезонных жителей в ней нет: побережье в августе людней, чем на карте.
- **Природа** — доля покрытия, не красота пейзажа. Голые плато считаются «полудикими», пастбища — дикими.
- Море, озёра и всё за границей страны замаскированы — там оценки нет.

## Добавить регион

1. Запись в `regions.config.mjs`: `id`, двуязычное `name`, `bbox`, `osmRelation` (relation страны/области — маска), код `worldpop`, тайлы `worldcover` (3°×3°, по юго-западному углу).
2. `npm run fetch -- <id>` — качает OSM (дороги, здания тайлами 0,25°, вышки, граница), ночной свет, WorldPop, WorldCover в `data/<id>/raw/` (не в git), затем собирает `public/data/<id>/grid.gz` + `meta.json` (в git).
3. Открыть `/?r=<id>`. Пороги в `src/core/index.ts` общие — проверьте их на новом регионе.

Overpass медленный и часто занят: `scripts/overpass.mjs` перебирает несколько публичных зеркал с паузами; `OVERPASS=<url>` — своё зеркало.

## Разработка

```bash
npm install
npm run dev        # http://localhost:4327
npm test           # ядро: оценки, кодирование, геометрия сетки, преобразование расстояния
npm run check      # astro check (TypeScript)
npm run test:e2e   # Playwright smoke: карта окрашена, клик даёт разбивку, веса меняют оценку
npm run build
```

Node ≥ 22.22 (`.nvmrc` = 24). Astro 7, MapLibre GL JS 6, без фреймворка. Файлы: `src/core/` — геометрия сетки, кодирование планов, формулы (общие для сборки, браузера и тестов); `src/scripts/` — страница; `scripts/` — конвейер данных.
