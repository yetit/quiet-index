# Quiet Index — Индекс тихого места

[![Build and deploy](https://github.com/yetit/quiet-index/actions/workflows/deploy.yml/badge.svg)](https://github.com/yetit/quiet-index/actions/workflows/deploy.yml) [![Smoke](https://github.com/yetit/quiet-index/actions/workflows/live.yml/badge.svg)](https://github.com/yetit/quiet-index/actions/workflows/live.yml)

**Демо: <https://yetit.github.io/quiet-index/>**

**Где тихо, темно и далеко от людей?** Карта, которая оценивает любую точку региона от 0 до 100 — для путешественников, кемпинга и тех, кто ищет, куда уехать поработать. Всё на открытых данных, расчёт в браузере: без сервера и ключей.

English: [README.md](README.md).

Регионы: Черногория, Албания, Босния и Герцеговина, Косово, Сербия и Далмация (Сплитско-Далматинская жупания, Хорватия), сетка ~250 м. Архитектура «любой регион»: bbox в `regions.config.mjs`, одна команда, результат в git. Метод, пороги и сверка с картами шума ЕС — на [странице метода](https://yetit.github.io/quiet-index/method/).

## Что видно

- **Карта** окрашена индексом сразу при входе (предрассчитанная сетка — один файл ~1 МБ). Чипы переключают на отдельный слой: тишина, темнота, безлюдье, природа, связь.
- **Клик по точке** — оценка, пять оценок по слоям и измерения, из которых они сложились: расстояние до ближайшей дороги и её класс (и закрыта ли она хребтом), до железной дороги, аэропорта, ближайшего здания и вышки, ночная радиометрия с приблизительным классом Бортля, плотность населения, доли леса / воды / открытых земель.
- **Тише рядом**: лучшие клетки в 10 / 30 / 100 км от точки с разносом не меньше 2 км, в один клик. **Примеры** в пустой панели — для первого захода.
- **Сравнение двух точек**: закрепить A, кликнуть B, получить таблицу (`?a=lat,lon` в ссылке).
- **Веса** — ползунки. Индекс — взвешенное среднее пяти слоёв, ничего скрытого. «Связь» по умолчанию с весом 0 — поднимите, если нужен интернет.
- **Поиск места** (Photon), **«Где я»** (геолокация), **RU / EN**, лист снизу на телефоне и всё состояние в ссылке (`?p=lat,lon&w=…&l=…&lang=…`).
- **Работает офлайн.** Это PWA: после первого визита service worker хранит страницу, сетку и просмотренные тайлы подложки, так что карта и оценки открываются в палатке без связи (установить можно из меню браузера). Поиску места сеть нужна.

## Как считается

Каждая клетка (~250 м, квадратная в Web Mercator) получает пять оценок 0–100. Пороги — эвристики, подобранные по пилотному региону, все в одном файле: [src/core/index.ts](src/core/index.ts).

| Слой | 100 — это | 0 — это | Формула |
|---|---|---|---|
| **Тишина** | ни дороги, ни улицы, ни ж/д, ни аэропорта в пределах слышимости | прямо на дороге | `min` по источникам от `расстояние / радиус`, линейно; радиусы: motorway 2,5 км, trunk 2 км, primary 1,2 км, secondary 700 м, tertiary 400 м, улица residential / unclassified 150 м, ж/д 1 км, аэропорт 4 км. Если ближайшая точка источника не видна из клетки по рельефу (линия видимости по DEM 90 м, приёмник 1,5 м, источник 0,5 м над землёй), расстояние считается втрое большим — грубо −5 дБ для линейного источника |
| **Темнота** | ночная радиометрия ≤ 0,25 нВт/(см²·ср) | ≥ 50 нВт/(см²·ср) | лог-шкала между порогами; для справки показывается приблизительный класс Бортля (шкала описывает яркость неба, спутник видит свет земли) |
| **Безлюдье** | никого в 2×2 км и ни одного здания в радиусе 1 км | плотный город, дом прямо здесь | среднее лог-оценки плотности (0 при ≥ 5 000 чел/км²) и `расстояние до здания / 1 км` |
| **Природа** | 2×2 км леса и воды | пашня или застройка | лес % + вода % + ½ · открытые естественные земли % (кустарник, луга, скалы, снег, болота) |
| **Связь** | вышка из OSM в радиусе 1 км | ни одной в 8 км | линейно от 1 до 8 км; **данные неполные**, см. ограничения |

Индекс = Σ вес · оценка / Σ вес. Веса по умолчанию: тишина 35, темнота 25, безлюдье 20, природа 20, связь 0.

Тяжёлая часть — один раз при сборке данных (`npm run fetch -- montenegro`, около 8 с расчёта после загрузок): расстояния — точное евклидово преобразование расстояния на подсетке в 5 раз мельче (~50 м), оно же даёт точку ближайшего источника для проверки видимости; население и покрытие — суммы по окну 2×2 км через интегральные таблицы. Продукт — два файла: `scores.gz` (маска и пять оценок, 359 КБ для Черногории) красит карту сразу, `grid.gz` (все измерения, 1,4 МБ) подгружается следом для панели. Сдвиг ползунка перекрашивает все 526 000 клеток за миллисекунды.

### Сверка с картами шума ЕС

Европейское агентство по окружающей среде публикует контуры Lden по директиве END — для крупных дорог (> 3 млн машин в год) и агломераций. Черногория не покрыта. Для Далмации контуры есть, `node scripts/compare-end.mjs dalmatia` берёт их в центрах клеток ([docs/end-check-dalmatia.md](docs/end-check-dalmatia.md)):

| Lden | клеток | медиана «Тишины» | «тихо» (≥ 60) |
|---|---|---|---|
| 55–59 дБ | 745 | 8 | 1 % |
| 60–64 дБ | 383 | 4 | 0 % |
| 65–74 дБ | 277 | 2 | 0 % |
| ≥ 75 дБ | 78 | 2 | 0 % |

Внутри контуров оценка низкая и падает с ростом Lden — порядок порогов верный. В децибелах сверка их не калибрует, а 98 % клеток вне контуров смешивают по-настоящему тихие места и дороги, которые END не картирует.

| Слой | Источник | Лицензия | Примечания |
|---|---|---|---|
| Дороги, ж/д, аэропорты, здания, вышки, граница | [OpenStreetMap](https://www.openstreetmap.org/copyright), выгрузки [Geofabrik](https://download.geofabrik.de/) по странам (PBF) | ODbL 1.0 | Дороги: `motorway … tertiary` с их `_link`, плюс `residential` и `unclassified` одним классом «улица». | Рельеф | [Copernicus DEM](https://registry.opendata.aws/copernicus-dem/) GLO-90 на AWS Open Data | лицензия Copernicus (свободное использование с указанием) | Только для линии видимости. |
| Карты шума (только сверка) | [EEA](https://www.eea.europa.eu/), контуры END Lden от дорог, ImageServer, обновление апреля 2026 | © European Environment Agency | В индекс не входят; `scripts/compare-end.mjs`. |

### Что планировалось и чем заменено

- **Карты шума ЕС (END / EEA)** как эталон: Черногория не покрыта, поэтому сверка сделана на Далмации (см. выше).
- **VNP46A4 (годовой Black Marble)** требует токен Earthdata; **годовые композиты EOG** — регистрацию; **World Atlas** (Falchi 2016) — CC BY-NC и 684 МБ. → Суточный VNP46A2 через GIBS (без ключа), медиана 24 ночей.
- **GHS-POP** — архивы тайлов 10°×10° по сотни МБ; **WorldPop** даёт файл по стране в 10 МБ с той же по сути лицензией (CC BY 4.0). → WorldPop.
- **Copernicus Global Land Cover (CGLS-LC100)**: публичный S3-бакет в октябре 2026 отвечает 404. → ESA WorldCover 2021, тоже CC BY 4.0 и детальнее.
- **OpenCelliD** требует ключ; открытые данные **Ookla / nPerf** — CC BY-NC-SA. → Вышки из OSM, слой выключен по умолчанию и помечен как неполный.

## Ограничения — прочитайте, прежде чем верить числу

- **Эвристики, не акустика.** Класс дороги заменяет трафик; ветер, ограничения скорости и время суток не учитываются. Экранирование рельефом — одна линия видимости до ближайшей точки источника по DEM 90 м: хребет считается плоскими −5 дБ, портал тоннеля или виадук не распознаются.
- **Улицы слышны только в 150 м.** `residential` и `unclassified` — один класс с коротким радиусом; `service`, `track` и тропы — не источники вовсе. Оживлённая деревенская улица и тупиковый проезд выглядят одинаково.
- **Клетки 250 м.** Клик привязывается к центру клетки, расстояния могут отличаться до ~180 м. Хранятся с шагом 25–100 м.
- **Полнота OSM.** Здания хорошо отмечены в городах и неровно в сёлах; вышки связи — лишь местами. «Связь» — подсказка, а не покрытие. Дороги соседних стран у границы учтены ровно настолько, насколько перечислены их выгрузки.
- **Ночной свет** — пиксели ~450 м; снег, пожары и огни судов его завышают; только 2025 год.
- **Население** — модель 2020 года (WorldPop), туристов и сезонных жителей в ней нет: побережье в августе людней, чем на карте.
- **Природа** — доля покрытия, не красота пейзажа. Голые плато считаются «полудикими», пастбища — дикими.
- Море, озёра и всё за границей страны замаскированы — там оценки нет.
- **Офлайн** покрывает только тайлы подложки, просмотренные с сетью (до ~2 000); в остальных местах индекс рисуется поверх пустого фона.

## Добавить регион

1. Запись в `regions.config.mjs`: `id`, двуязычное `name`, `bbox` (целиком вмещает границу), пути `geofabrik` (сначала своя выгрузка, затем соседи, чьи дороги важны у границы), `boundary` (`{ iso: 'ME' }` для страны или `{ relation: id }` для любой границы OSM), код `worldpop`, три `examples`.
2. `npm run fetch -- <id>` — качает выгрузки Geofabrik (страна и соседи, общие в `data/pbf/`, читает `scripts/pbf.mjs` без Overpass), ночной свет, WorldPop, WorldCover и DEM в `data/<id>/raw/` (не в git), затем собирает `public/data/<id>/scores.gz`, `grid.gz` и `meta.json` (в git). Ежемесячный workflow `data.yml` заново выгружает все регионы и открывает PR, если продукт изменился.
3. Открыть `/?r=<id>`. Пороги в `src/core/index.ts` общие — проверьте их на новом регионе.

Выгрузки читаются дважды (сначала relations, потом узлы в bbox и way); страна размером с Сербию вместе с соседями — несколько минут и около 1 ГБ памяти под таблицу узлов.

## Разработка

```bash
npm install
npm run dev        # http://localhost:4327
npm test           # ядро: оценки, кодирование, геометрия сетки, преобразование расстояния
npm run check      # astro check (TypeScript)
npm run test:e2e   # Playwright smoke: карта окрашена, клик даёт разбивку, веса меняют оценку, примеры / тише рядом / сравнение, геолокация, офлайн-перезагрузка (нужна сборка: astro preview)
node scripts/compare-end.mjs dalmatia   # сверка с контурами шума EEA → docs/
node scripts/og.ts                      # OG-картинка с поднятого сервера
npm run build
```

CI: `deploy.yml` (check, тесты, сборка, GitHub Pages) и `live.yml` после каждого деплоя — Playwright smoke против живого демо и Lighthouse (мобильный профиль, три прогона, медиана) с порогами в `lighthouserc.json` ниже замеренного: на раннере карта даёт 57 / 100 / 100 / 100 (LCP 5,0 с, TBT 0,85 с, мобильный профиль), страница метода — 100 по всем категориям; пороги — 0,45 и 0,9 по производительности, 0,95 по остальным. MapLibre грузится отдельным чанком после того, как панель уже на экране; первому кадру карты нужен только `scores.gz`.

Node ≥ 22.22 (`.nvmrc` = 24). Astro 7, MapLibre GL JS 6, без фреймворка. Файлы: `src/core/` — геометрия сетки, кодирование планов, формулы (общие для сборки, браузера и тестов); `src/scripts/` — страница; `scripts/` — конвейер данных.
